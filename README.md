# Modelagem inversa para Inadimplência Macro do Brasil 

O problema de Inadimplêcia é algo corriqueiro e presente na vida de milhões de Brasileiros atualmente. Mas quais sãos os principais fatores que influenciam a inadimplência crescer ou diminuir? 

Nesse projeto eu vou além de um estudo temporal, causal, de área ou uma previsão. Eu quero a partir dos historicos atuais dos dados, modelar inversamente o problema. Ou seja, quero a partir de um valor desejado y (inadimplência), encontrar os espaços onde esse valor pode flutuar. 


As linguagens usadas nesse trabalho são, majoritariamente, Python e C. 

A escolha não tão convencional do C nesse projeto deve-se pelo fato de ser uma linguagem que consegue interpretar grandes quantidades de operações numéricas sem grande custo computacional, algo que valorizo muito na hora de escolher com o que trabalhar. Além disso, o C me permite ter total controle sobre as matrizes que estou construindo, me ajudando a interpretar a fundo o que está acontecendo nesse mar de contas matemáticas, algo que não ocorre no uso de bibliotecas prontas, como Scipy e Scikit-Learn no Python.
