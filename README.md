# Modelagem inversa para Inadimplência Macro do Brasil 

O problema de Inadimplecia é algo corriqueiro e presente na vida de milhoes de Brasileiros atualmente. Mas quais sãos os principais fatores que influenciam a inadimplencia crescer ou diminuir? 

Nesse projeto eu vou além de um estudo temporal, causal, de área ou uma previsão. Eu quero a partir dos historicos atuais dos dados, modelar inversamente o problema. Ou seja, quero a partir de um valor desejado y (inadimplecia que quero alcançar), encontrar os espaços onde esse valor pode flutuar.
